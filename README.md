# 天体高度・方位角観測ビューア

観測地（緯度・経度）と観測日時を入力することで、主要15星座の高度・方位角をリアルタイムに算出して表示する天体観測支援ツール。ボルトル尺度別の望遠鏡推奨倍率ガイドと、星座ごとの観測ベストシーズンカレンダーも収録。

## 機能
- 観測地（緯度・経度）・日時の入力フォーム（東京デフォルト・今日の日付自動設定）
- 15星座の高度・方位角・観測状態（最良/良好/低空/地平下）をテーブル表示
- 簡易天文計算（恒星時・時角・高度公式 Alt=arcsin...）による近似値算出
- 星座観測ベストシーズン12ヶ月カレンダー（最良/良好/不可のカラー表示）
- ボルトル尺度1〜9レベル別の推奨倍率・推奨対象天体ガイド
